1. 전체 상담 버튼 구조
데스크톱

화면 오른쪽에 전화·카카오 상담 버튼을 세로로 고정합니다.

┌──────────────┐
│ ☎ 전화 상담 │
├──────────────┤
│ 💬 카카오 상담 │
└──────────────┘

적용 기준:

position: fixed
화면을 내려도 계속 표시
오른쪽 24px, 화면 중간 또는 하단 32px
버튼 높이 48px 이상
아이콘만 표시하지 말고 전화 상담, 카카오 상담 텍스트 포함
애니메이션·깜빡임·흔들림 금지
카카오 링크는 처음부터 HTTPS 사용
데스크톱 전화 버튼 클릭 시 전화번호와 번호 복사를 보여주는 작은 팝업
전화가 가능한 기기에서는 바로 tel: 연결

화면 너비에 따른 처리:

1280px 이상: 아이콘+텍스트 버튼
768~1279px: 52px 원형 아이콘, 마우스를 올리면 설명 표시
767px 이하: 우측 버튼 숨김
모바일

우측 플로팅 대신 하단 고정 바를 사용합니다.

┌─────────────────────────┐
│ 전화 상담 │ 카카오 상담 │
└─────────────────────────┘
기존 하단 버튼의 사진 상담을 카카오 상담으로 변경
사진 상담은 각 페이지 본문의 주 CTA로 유지
버튼 높이 최소 48px
하단 안전영역 적용
본문과 푸터에 최소 88px 하단 여백
키보드가 열리면 하단 바가 입력창을 가리지 않도록 처리

상단 메뉴의 상담 항목은 삭제해도 됩니다. 우측 고정 상담과 각 페이지의 사진 상담 버튼이 있기 때문에 중복입니다.
