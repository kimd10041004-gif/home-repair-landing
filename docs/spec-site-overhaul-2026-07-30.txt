현재 개발 중인 기존 반듯집수리 홈페이지 프로젝트를 전면 개편해라.

다른 사이트의 디자인·문구·이미지·레이아웃을 복제하지 말고 다음 구조적 장점만 참고해라.

* 고객이 얻게 되는 생활 변화를 먼저 설명
* 문제 → 해결 → 서비스 → 과정 → 상담 순서
* 메인 랜딩페이지와 서비스별 상세페이지 구성
* 사진과 정적인 UI 카드 중심의 설명

이번 버전에는 자동재생 영상, 영상관, 가짜 영상 링크를 구현하지 마라. 실제 작업 영상이 없으므로 영상 공간이나 “영상 준비 중” 문구도 만들지 않는다.

단순한 디자인 제안서만 작성하지 말고 기존 코드를 직접 확인한 뒤 실제 페이지를 수정하고 빌드·테스트까지 완료해라.

# 1. 작업 원칙

1. 프로젝트 구조, 프레임워크, 기존 페이지, 컴포넌트, 스타일, 이미지, 상담 기능, 환경설정, 테스트와 Git 상태를 먼저 확인한다.
2. 정상 작동하는 전화·카카오톡·사진상담 기능과 기존 사용자 변경사항을 보존한다.
3. 기존 기능을 임의로 삭제하지 않는다.
4. 서비스·가격·후기·사업자정보·자격·보험·제휴업체를 임의로 만들지 않는다.
5. 실제 결제, 외부 메시지 발송, Secret 입력, 운영 배포는 사용자 승인 없이 하지 않는다.
6. 테스트 과정에서 실제 상담 문의를 전송하지 않는다.
7. 수정 후 lint, typecheck, test, production build를 실행한다.
8. 단순 진행 보고만 하고 중간에 멈추지 말고 구현과 검증을 완료한다.

# 3. 공통 운영정책

홈페이지 전체에 다음 기준을 일관되게 적용한다.

* 서비스 지역: 서울·경기 전 지역
* 출장비: 방문 1회당 20,000원
* 같은 방문의 여러 작업에는 출장비 한 번만 적용
* 유료주차비·고속도로 통행료는 사전 안내 후 실제 발생액 별도
* 시공상 하자로 확인된 무상 A/S 방문에는 출장비 없음
* 사진으로 안내하는 금액은 사전예상액
* 최종 금액은 현장 상태와 작업 범위를 확인한 뒤 확정
* 고객 동의 없는 추가 작업 없음
* 제품비·자재비·별도 옵션은 견적서에서 구분
* 기본 구매대행비: 동일 판매처 1회 주문 기준 30,000원
* 추가 주문·특수 운반·화물배송은 사전 승인 후 별도
* 추가공임: 작업자 1인 기준 30분당 50,000원
* 2인 작업은 투입 인원에 비례
* 추가 작업은 내용·금액·승인 시각을 안내하고 고객이 동의한 뒤 진행
* 견적 유효기간: 발송일로부터 7일
* 홈페이지 공개 금액은 VAT 포함

금지 표현:

# 4. 계약금과 결제정책

기존 고정 예약금 40,000원 정책은 완전히 삭제한다.

최종 정책:

1. 사진상담 또는 필요한 경우 현장 실측 후 견적서와 주요 거래조건을 발송한다.
2. 고객이 승인한 뒤 제품비·자재비를 제외한 계약대상 서비스 금액의 30%를 계약금으로 결제하면 일정이 확정된다.
3. 서비스 금액에는 견적서에 포함된 공임·설정비·출장비·구매대행비가 들어간다.
4. 계약금은 별도 수수료가 아니라 총대금의 일부이며 잔금에서 전액 차감한다.
5. 반듯집수리가 대리구매하는 제품비·자재비는 고객 승인 후 구매 전에 전액 별도로 결제한다.
6. 작업 완료와 작동 확인 후 잔금과 고객이 승인한 추가 작업비를 결제한다.
7. 실제 온라인 결제 기능이나 결제대행사를 새로 연결하지 않는다.

공개 문구:

“사진상담 또는 필요한 경우 현장 실측 후 견적서를 보내드립니다. 견적서와 주요 거래조건을 확인한 뒤, 제품·자재비를 제외한 계약대상 서비스 금액의 30%를 계약금으로 결제하면 일정이 확정됩니다. 구매대행 제품·자재비는 고객 승인 후 구매 전에 별도로 결제합니다. 계약금은 총 작업대금에 포함되며 잔금에서 전액 차감됩니다.”

취소·환불 문구:

“계약금은 총 작업대금의 일부로 선지급되는 금액입니다. 취소·환불은 관계 법령을 우선 적용하며, 이미 제공된 실측·작업과 고객 승인 후 구매한 주문제작품 또는 실제로 회수하지 못한 제품·자재비가 있는 경우 증빙을 기준으로 정산합니다. 주문 취소나 반품으로 회수된 금액은 고객 부담액에서 제외합니다. 반듯집수리 사정으로 작업이 취소되는 경우 수령한 계약금과 제품·자재비를 전액 반환합니다.”

계약금 30%를 자동 환불불가 위약금으로 표현하지 않는다.

* 동의 없는 추가 작업 없음

# 9. 스마트홈 고객 보호

스마트홈 페이지에 다음 내용을 표시한다.

* 고객이 본인 명의로 계정을 생성하고 비밀번호를 직접 입력
* 반듯집수리는 비밀번호·인증번호를 보관하지 않음
* 완료 후 계정 통제권과 관리자 권한을 고객에게 인계
* 홈캠 영상을 반듯집수리가 저장하지 않음
* 부모님 케어 기능은 거주자 동의를 전제로 설정
* 의료·건강상태를 판단하는 서비스가 아님
* 인터넷·클라우드 장애 시 일부 원격 기능이 제한될 수 있음
* 매립형 전기작업 등 자격·등록이 필요한 작업은 전문업체에 이관

# 10. 작업사례

탭:

카드:

가짜 후기·고객 이름·별점·시공 건수·사업 연혁을 만들지 않는다. 콘텐츠가 없으면 빈 가짜 카드를 만들지 말고 해당 영역을 숨긴다.

# 11. 사진상담

첫 질문:

“어떤 서비스가 필요하신가요?”

선택:

* 생활 집수리
* 세입자·주거 케어
* 스마트홈 IoT 케어

선택에 따라 질문과 사진 요구사항을 분기한다.

필수 검증:

* 이름
* 연락처
* 시·구·동
* 희망일 1지망
* 서비스별 필수 사진
* 필수 거래조건 확인
* 필요한 개인정보 처리 고지

사진 기본:

1. 공간 전체
2. 문제 부위 근접
3. 제품 정보·연결부

규격 작업:

* 가로·세로 정면
* 측정도구를 댄 사진
* 제품 모델명·규격

업로드:

* 최소 필수 사진 검증
* 허용 파일 종류·크기·장수 표시
* 업로드 실패 사유 표시
* 사진에 불필요한 위치정보·가족사진·개인정보가 포함되지 않도록 안내

개인정보:

* 수집 목적
* 수집 항목
* 보유기간
* 처리 근거
* 거부권과 불이익
* 필수·선택 구분
* 포트폴리오·후기·광고 수신은 각각 선택 동의
* 선택 동의 거부로 상담·계약·시공·A/S 제한 금지
* 개인정보처리방침 연결

기존 상담 저장·알림 기능은 보존한다. 외부 서비스나 Secret이 필요하면 임의로 추가하지 말고 구현 가능한 범위까지만 완료한 뒤 보고한다.

# 12. 디자인

색상:

* 딥 네이비 `#17324D`
* 웜 아이보리 `#F7F5EF`
* 체크 틸 `#2F9C8F`
* 흰색 `#FFFFFF`
* 진회색 `#263238`

방향:

* 깔끔한 주거공간
* 친근하지만 가볍지 않은 전문가
* 기술회사보다 생활서비스 브랜드에 가까운 인상
* 기존 로고 유지
* 넓은 여백과 큰 제목
* 과도한 그라데이션·네온·유리효과 금지
* 공구만 강조한 흔한 이미지 남용 금지
* 여성 고객의 불안을 자극하는 이미지 금지
* 다크모드 자동전환 금지
* 영상·자동재생·소리 나는 미디어 금지

이미지는 데이터로 관리한다.

* 제목
* 설명
* 서비스 분류
* 이미지
* 대체텍스트
* 실제 사례 여부
* 공개 여부

이미지가 없거나 비공개이면 레이아웃이 깨지지 않아야 한다.
