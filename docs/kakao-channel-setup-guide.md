# 카카오톡 채널 버튼 설정 가이드 (비개발자용)

이 문서는 카카오톡 채널을 "AI 챗봇"이 아니라 **버튼형 자동응답 + 홈페이지 링크 연결** 수준으로
설정하는 절차입니다. 개발 지식 없이 카카오 채널 관리자센터에서 직접 따라 하실 수 있습니다.

> 원칙: 카카오톡은 안내·분류·상담 연결 창구입니다. 필수 사진과 개인정보가 들어가는
> 정식 견적 접수는 반드시 홈페이지(`https://<도메인>/estimate`) 신청폼에서 처리합니다.
> 카카오톡 대화창에 고객이 사진을 보내더라도 그것을 정식 접수로 처리하지 않습니다.

---

## 1. 준비물

- 카카오톡 채널 관리자센터 로그인 (https://center-pf.kakao.com)
- 반듯집수리 채널 관리자 권한
- 홈페이지 견적 신청 페이지 주소: `https://<홈페이지 도메인>/estimate`

## 2. 메인 메뉴(홈 탭) 버튼 구성

1. 관리자센터 접속 → 좌측 메뉴에서 **[홈]** 탭 선택
2. **[메뉴 관리]** 또는 **[홈 설정]**에서 버튼(바로가기) 6개를 아래와 같이 등록합니다.

| 버튼 이름 | 동작 유형 | 연결 내용 |
|---|---|---|
| 사진 견적 신청 | 웹링크 | `https://<도메인>/estimate` |
| 서비스·가격 안내 | 웹링크 | `https://<도메인>/services` |
| 출장 가능 지역 | 텍스트 응답 | "서울·경기 전지역 방문 가능합니다. 다만 외곽 지역은 출장비가 추가될 수 있습니다." |
| 예약 변경·취소 | 텍스트 응답 + 상담연결 | "예약 변경/취소는 상담원 연결 후 안내드립니다. 예약 확정을 위해 입금하신 예약금 4만원은 일정 확보 및 사전 준비 비용으로 사용되어 환불이 어려운 점 양해 부탁드립니다." → 상담원 연결 버튼 노출 |
| A/S 접수 | 텍스트 응답 + 상담연결 | "A/S 접수는 접수번호 또는 연락처를 남겨주시면 확인 후 연락드립니다." |
| 상담원 연결 | 상담연결(채팅 전환) | 카카오 채널의 "상담톡" 기능으로 연결 |

> 채널이 "챗봇" 빌더(오픈빌더)를 사용하지 않는 경우, [홈] 탭의 "메뉴/버튼" 설정만으로
> 위 구성이 대부분 가능합니다. 오픈빌더가 이미 연결되어 있다면 3번 절차를 따르세요.

## 3. (오픈빌더 사용 중인 경우) 버튼형 시나리오 설정

오픈빌더에서 새 "AI 대화형 시나리오"를 만들지 말고, **폴백 블록 + 바로연결 버튼**만 사용합니다.

1. 오픈빌더 관리자센터 → 해당 봇 선택
2. **[시나리오] → [웰컴 블록]** 편집
3. 웰컴 메시지에 아래 문구와 6개 바로가기 버튼(quick reply / 바로가기)을 등록:
   - 사진 견적 신청 / 서비스·가격 안내 / 출장 가능 지역 / 예약 변경·취소 / A/S 접수 / 상담원 연결
4. 각 버튼의 동작은 "블록 이동" 대신 **"웹링크 열기"** 또는 **"텍스트 답변 후 종료"**로 설정
   (복잡한 대화 흐름/AI 응답 블록은 만들지 않습니다.)
5. "사진 견적 신청" 버튼을 누르면 아래 안내문을 먼저 보여준 뒤 링크 버튼을 노출합니다.

### 사진 견적 신청 버튼 안내 문구 (그대로 복사해서 사용)

```
사진을 기준으로 작업 환경과 예상 비용 범위를 먼저 확인해 드립니다.
일반 수리는 고장 부위 사진이 최소 3장 필요합니다.
방충망·문·창문·타일·선반 등 규격 확인이 필요한 작업은 정면 사진과
가로·세로 측정 사진이 필요합니다.
아래 버튼을 눌러 견적 신청서를 작성해 주세요.
[사진 견적 신청하기]
```

- "사진 견적 신청하기" 버튼의 링크 주소: `https://<도메인>/estimate`

## 4. 고객이 채팅창에 바로 사진을 보내는 경우

고객이 안내를 보지 않고 채팅창에 바로 사진을 보내는 경우가 있습니다. 이때는 아래처럼
**정식 접수가 아님을 반드시 알리는 자동/수동 응답**을 보내주세요.

```
사진 감사합니다! 다만 카카오톡으로 보내주신 사진은 정식 견적 접수로 처리되지 않습니다.
정확한 예상 견적 안내를 위해 아래 링크에서 신청서를 작성해 주시면
필수 사진과 정보를 한 번에 접수해드릴 수 있습니다.
[사진 견적 신청하기] → https://<도메인>/estimate
```

- 오픈빌더를 쓰는 경우, "이미지 발화" 폴백 블록에 위 문구를 등록해두면 자동으로 안내할 수 있습니다.
- 폴백 블록이 없다면 상담원이 수동으로 위 문구를 복사해 답장합니다.

## 5. 상담원 연결 설정

1. 관리자센터 → **[상담] → [상담 관리]**에서 상담 가능 시간, 담당자 계정을 등록
2. "상담원 연결" 버튼을 누르면 상담톡으로 전환되도록 연결 설정
3. 상담 시간 외에는 자동 안내(예: "상담시간은 평일 09:00~18:00입니다. 남겨주신 메시지는 확인 후 연락드립니다.")를 등록

## 6. 점검 체크리스트

- [ ] 사진 견적 신청 버튼 → `/estimate` 링크 정상 연결 확인
- [ ] 서비스·가격 안내 버튼 → `/services` 링크 정상 연결 확인
- [ ] 출장 가능 지역 텍스트 응답 문구 확인
- [ ] 이미지 발화 시 "정식 접수 아님" 안내 자동/수동 응답 확인
- [ ] 상담원 연결 동작 확인 (실제 계정으로 테스트 메시지 발송)

## 7. 향후 확장 (지금은 진행하지 않음)

접수 데이터가 충분히 쌓인 뒤, 필요하다면 오픈빌더 기반의 AI 대화형 시나리오봇으로
확장하는 것을 검토할 수 있습니다. 현재 단계에서는 버튼형 자동응답 + 홈페이지 링크
연동까지만 운영합니다.
